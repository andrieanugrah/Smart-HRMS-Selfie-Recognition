# Audit Landing Page — Smart HRMS

- Tanggal: 2026-08-17
- Scope: `apps/web/src/app/page.tsx`, `apps/web/src/components/landing/landing-page.tsx`, `landing-footer.tsx`, `globals.css`
- Metode: antislop Mode 2 (After)

## Hasil

Tidak ada em dash (R-02 pass). Navbar tanpa ghost link (R-24 pass). Theme toggle bekerja dua mode (R-34 pass). Radius bervariasi (R-11 pass). Palette charcoal + cyan + semantic (R-29 pass). Section rhythm bervariasi, bukan template monoton (R-05 pass untuk komposisi).

### HIGH

**1. Statistik palsu di section "Angka yang bicara"** — `landing-page.tsx:27` (`DARK_STATS`)
- Rule: R-17, R-36, R-38
- `2.4k karyawan aktif`, `99.2% akurasi verifikasi`, `3.8k presensi per bulan`, `12 mnt hemat waktu`. Tidak ada sumber nyata. Akurasi 99.2% klaim performa tanpa bukti.
- Fix: hapus section, atau ganti angka dengan `[REAL DATA]` / metrik yang benar-benar terukur dari sistem.
- **✅ DONE** — section "Angka yang bicara" + `DARK_STATS` dihapus.

**2. Logo "Dipakai tim HRD" fiktif** — `landing-page.tsx:10` (`TRUSTED_LOGOS`) + `:51`
- Rule: R-18, R-36, R-38, R-05 (Trusted By bar)
- 6 perusahaan fiktif (Nusantara, Maju Bersama, dll.) + claim "Dipakai tim HRD di berbagai perusahaan" + "Diuji di lingkungan produksi sejak 2024". Semua fabricated trust.
- Fix: hapus bar logo + kedua claim. Ganti dengan social proof nyata atau kosongkan.
- **✅ DONE** — `TRUSTED_LOGOS`, `LogoMark`, dan section "Dipakai tim HRD" dihapus.

### MEDIUM

**3. Panah di hampir setiap CTA** — `landing-page.tsx` (7 tombol/tautan pakai `ArrowUpRight`/`ArrowDown`)
- Rule: R-08
- "Masuk", "Pelajari fitur", "Lihat alur lengkap", "Buka portal" x2, "Masuk ke aplikasi" x2. Arrow jadi default identitas.
- Fix: sisakan panah di CTA utama saja, hapus sisanya.
- **✅ DONE** — panah tersisa di CTA hero primary (`Masuk ke aplikasi`) saja.

**4. CTA generik** — `landing-page.tsx:57,61`
- Rule: R-15
- "Pelajari fitur", "Buka portal", "Lihat alur lengkap" tidak menyebut aksi nyata.
- Fix: "Lihat demo dashboard karyawan", "Masuk sebagai HRD", dst.
- **✅ DONE** — "Lihat fitur inti", "Buka portal karyawan/HRD", "Coba akun demo".

**5. "Cara kerja" selalu 3 langkah** — `landing-page.tsx:18` (`HOW_STEPS`)
- Rule: R-05
- 01/02/03 + icon. Layout divide-y (lebih baik dari card) tapi tetap pola 3-step standar.
- Fix: pertimbangkan 4 langkah atau ganti struktur bila narasi produk butuh.
- **✅ DONE** — jadi 4 langkah akurat: onboarding → selfie → approval → ekspor.

**6. Label monospace uppercase bertebaran** — `landing-page.tsx` (`FITUR INTI`, `ALUR KERJA`, `ANGKA YANG BICARA`, dll.)
- Rule: R-06
- `font-mono uppercase tracking-[0.2em]` dipakai sebagai eyebrow di tiap section tanpa alasan brand yang ditulis. Mono untuk data (angka/spec) OK, tapi sebagai label judul ini pola AI.
- Fix: tulis alasan (brand "lab terminal") di DESIGN.md, atau kurangi jadi satu tipe eyebrow.
- **✅ DONE** — eyebrow section jadi sans. Mono dipakai ulang untuk data, spec, dan angka saja.

### LOW

**7. Komponen `Reveal` mati** — `landing-page.tsx:29`
- Rule: C-1, C-2
- Prop `delay` diterima tapi tidak dipakai. Tidak ada animasi. Class `.reveal`/`reveal-up` di `globals.css:314` tidak pernah dipakai komponen ini.
- Fix: hapus `Reveal` + `delay`, pakai `<div>` langsung. Atau aktifkan animasi bila MOTION dial naik.
- **✅ DONE** — komponen `Reveal` + prop `delay` dihapus, semua jadi `<div>` polos. MOTION dial dideklarasi 1 (hover only).

**8. Tidak ada DESIGN.md** — repo
- Rule: R-37
- Arah desain ada di comment CSS (`Calm Charcoal + Biometric Cyan`) tapi tidak diformalkan. Dials ENERGY/RHYTHM/MOTION tidak dideklarasikan.
- Fix: tulis DESIGN.md singkat dengan palette, typography, dan ketiga dial.
- **✅ DONE** — `DESIGN.md` dibuat: identity, palette, typography, dials ENERGY 1 / RHYTHM 2 / MOTION 1, motif.
